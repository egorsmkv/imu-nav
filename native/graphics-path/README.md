# AndroidX Graphics Path — Rust port

Compose iterates `android.graphics.Path` through `androidx.graphics:graphics-path`. From
Android 14 that uses the platform `PathIterator`; before that, the AndroidX Kotlin code calls
a small JNI library that reads Skia's private `SkPathRef`. This crate is a Rust port of that
library for version **1.0.1**, replacing the C++ that used to live in `app/src/main/cpp`.

## Why it exists

The prebuilt `libandroidx.graphics.path.so` in the 1.0.1 and 1.1.0 AARs aligns LOAD segments
to 16 KB but ends GNU_RELRO at `0x6000`, which is not a 16 KB boundary. This crate's `build.rs`
links with `max-page-size` and `common-page-size` of 16 KB, like the other Rust libraries.
The Gradle artifact transform in `app/build.gradle.kts` removes the prebuilt library; the
AAR's Kotlin classes stay unchanged and call this library.

## Contents

- `src/conic.rs` — conic → quadratic subdivision (`Conic.cpp`), same float operations.
- `src/iterator.rs` — verb/point walk (`PathIterator.cpp`) over bounds-checked slices.
- `src/bridge.rs` (Android only) — `JNI_OnLoad`, the eight registered native methods and the
  `SkPathRef` layouts for Android 7, 8–10 and 11+ (`Path.h`).

Behaviour is identical to the C++ for valid paths. Differences, all in cases where the C++
reads or writes out of bounds: a malformed path ends with `Done`; `internalConicToQuadratics`
never writes more floats than the array holds (the C++ compared the quadratic count with the
float count) and returns the count so the Kotlin caller grows its array and retries.

## Verification

`tests/cpp_reference.rs` compares bit patterns with `tests/fixtures/cpp-reference.jsonl`:
483 conics (special weights/tolerances, NaN/infinity, degenerate and random) and 65 paths in
both verb layouts and both conic modes. The fixture was generated by
`tests/fixtures/reference.cpp` built with g++ 15.2 (`-std=c++17 -O2 -D__unused=`) against the
unchanged upstream `Conic.cpp`/`PathIterator.cpp` of AndroidX commit
`8a05a22af450d589ef911d772a001a49dcb05b71` (graphics/graphics-path/src/main/cpp). To
regenerate it, check out those files from that commit and build the harness the same way.

`app/src/androidTest/.../GraphicsPathNativeTest.kt` runs on devices: on Android 8–13 it
exercises this library against real Skia data.
